# ICT Hardware Inventory System - Screenshot Guide

## Purpose

This guide defines the exact screenshots needed for project documentation, user training, and demos.

## Recommended Screenshot Settings

- Resolution: 1920 x 1080
- Browser zoom: 100%
- Theme: Use one consistent theme for all captures
- Data: Keep non-sensitive sample data only
- Naming format: 01_filename.png, 02_filename.png, and so on

## Required Screenshot List

1. 01_dashboard_overview.png
- Capture full dashboard hero plus top summary/filter area.

2. 02_dashboard_filters_expanded.png
- Capture filters showing several dropdown values selected.

3. 03_dashboard_filtered_summary.png
- Capture updated matched reports and summary lists after filters.

4. 04_kpi_and_charts.png
- Capture KPI cards and primary chart row.

5. 05_inventory_table_view.png
- Capture inventory list/table view.

6. 06_item_detail_drawer.png
- Capture selected device detail panel/drawer.

7. 07_item_edit_modal.png
- Capture add/edit modal with key fields visible.

8. 08_supabase_login_modal.png
- Capture Supabase Admin Login modal.

9. 09_service_request_modal.png
- Capture service request modal workflow.

10. 10_ai_chat_panel.png
- Capture AI assistant panel with response visible.

11. 11_voice_controls.png
- Capture stop, pause, and resume controls during speech workflow.

12. 12_settings_modal.png
- Capture settings screen for available non-secret configuration options.

## Capture Workflow

1. Start from a clean browser window.
2. Navigate to each target screen.
3. Use built-in OS screenshot tool or browser extension.
4. Save in PNG format with filenames from the list above.
5. Store outputs under docs/screenshots.

## Folder Structure

Place screenshots in:
- docs/screenshots/

Recommended include in reports:
- docs/TECHNICAL_DOCUMENTATION.md
- docs/USER_MANUAL.md
- presentation slide deck for stakeholders
