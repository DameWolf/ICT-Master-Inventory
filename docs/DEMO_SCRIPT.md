# ICT Hardware Inventory System - Demo Script

## Demo Duration

Target: 8 to 12 minutes

## Demo Goals

- Show inventory visibility and reporting value
- Demonstrate filtering and summary workflow
- Show secure admin login and edit capability
- Highlight AI and voice enhancements (if configured)

## Demo Setup Checklist

Before demo:
1. Confirm environment variables are set.
2. Confirm sample inventory data is available.
3. Ensure internet connection is stable for external integrations.
4. Prepare at least one admin credential for Supabase login.

## Live Demo Flow

### 1) Opening (1 minute)
Script:
This system centralizes ICT hardware records, provides real-time summary views, and supports efficient filtering for reports and operations.

Action:
- Open dashboard home screen.

### 2) Dashboard Overview (2 minutes)
Script:
At the top, we can filter inventory records across multiple dimensions and instantly view updated summaries.

Action:
- Point to top filter section.
- Show summary cards and summary lists.
- Briefly review KPI and chart sections.

### 3) Advanced Filtering (2 minutes)
Script:
Let us filter by campus, department, and status to get a targeted operational snapshot.

Action:
- Apply 3 to 4 filters.
- Show Matched Reports and Coverage update.
- Use Reset Filters to return to full scope.

### 4) Inventory Detail and Edit Flow (2 minutes)
Script:
We can open any device record to inspect details and perform updates when authorized.

Action:
- Open an item detail view.
- Trigger edit flow.
- Show admin login requirement for protected actions.

### 5) Supabase Admin Login (1 minute)
Script:
Admin authentication secures edit operations and limits changes to authorized users.

Action:
- Open Supabase login modal.
- Sign in with demo admin account.
- Confirm protected action is available.

### 6) AI and Voice Features (Optional, 1 to 2 minutes)
Script:
The assistant can support operational queries, and voice controls improve accessibility and speed.

Action:
- Ask one AI prompt.
- Demonstrate stop/pause/resume on speech playback.

### 7) Closing (30 seconds)
Script:
This solution improves asset visibility, reporting efficiency, and operational control while keeping authentication and integration configurable.

## Suggested Q and A Topics

- Data source and sync strategy
- Role-based access control roadmap
- Audit logging and change history
- Deployment and backup strategy
